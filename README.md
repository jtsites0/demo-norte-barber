# NØRTE Barber — Projeto demonstrativo

Projeto fictício criado pela **JT Sites** para demonstrar uma direção visual premium para barbearias.

## Conceito
- identidade editorial em preto e bronze
- apresentação de serviços e preços ilustrativos
- fluxo demonstrativo de agendamento
- layout responsivo
- HTML, CSS e JavaScript sem dependências de build

> NØRTE Barber é uma marca fictícia. Nenhum preço, serviço ou agendamento representa um negócio real.

## GitHub Pages
